AdSells: запуск проекта

1. Установите Node.js 22.12 или новее.
2. Откройте папку AdSells в терминале.
3. Выполните npm ci
4. Выполните npm run dev
5. Откройте адрес, показанный в терминале.

Сборка: npm run build
Просмотр сборки: npm run preview

src: исходники TypeScript и CSS
public: фотографии
dist: готовая сборка для статического хостинга

Данные хранятся в браузере. Платежи и отзывы демонстрационные.
