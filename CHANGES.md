# AdSells — Glisse theme

## Обновление
- Палитра #14213D / #F4EDE0 / #FF6B5B по принципу 60/30/10: основа, контент, акценты. Это визуальное соотношение; доля пикселей меняется с фотографиями, прокруткой и шириной экрана.
- CSS Glisse подключён напрямую, с адаптером для существующих DOM-контролов. React и JS-механика преломления Glisse не подключались; реализованы размытие, прозрачность, обводки, состояния и формы элементов.
- Новая тема src/glass-theme.css; исходный CSS Glisse и лицензия в src/vendor/.
- Убраны тестовые подписи из интерфейса. Вымышленные отзывы и рейтинг заменены пустым состоянием.
- Подтверждения платежей заменены текстами заявки и стоимости заказа: платёжная интеграция не добавлялась.

## Проверки
npm run build: TypeScript + Vite успешно. В браузере проверены каталог, карточка, форма заявки и профиль. Мобильный первый экран проверен при ширине 390 px. Полный цикл заказа после изменения темы не проверялся.

## Технические границы
Данные по-прежнему сохраняются в localStorage. Сервер, аккаунты пользователей, реальные платежи и обмен сообщениями между устройствами не подключены. Удаление тестовых надписей меняет представление, а не инфраструктуру. Начальные объявления и профиль остаются примерами данных из исходного проекта.
